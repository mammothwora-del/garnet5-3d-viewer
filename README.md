# Garnet 5 Lamphun – 3D method statement

Interactive 3D build sequence for Warehouse W1: stage view (landfill and piling through to dock equipment) and month view (months 1–8 of master schedule Rev.4).

Open `index.html` through GitHub Pages. The model is built from STR Rev.2 / Option 1 Rev.2.1 and AR GARN5-LP R2 drawings.

The Overview and the end of month 8 show the full facade design model (SketchUp, 26.09.24), simplified to about 0.9 million faces in `facade.js`. Colours are approximate because the texture images were not exported. Untick “Facade design” to see the element model instead.
